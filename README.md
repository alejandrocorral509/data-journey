## 📌 Reglas del juego

1. **Más práctica que vídeos.** Al menos la mitad del tiempo, trabajando con datos reales.
2. **Cada día, una entrada en la bitácora y un commit.** El historial de GitHub es mi currículum.
3. **Cada proyecto responde preguntas de negocio**, no solo enseña gráficos. README con: pregunta → datos → método → hallazgos → recomendaciones.
4. **Nada de copiar los proyectos del curso.** Los cursos son para aprender; el portfolio es mío.
5. **Si me atasco más de 30 minutos**, lo apunto en la bitácora y pregunto.
